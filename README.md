# The AbAI-ed Specification (v0.1)
**Assisted by Artificial Intelligence**

## 1. Overview
The **AbAI** (Assisted by AI) standard and the **AbAI-ed** status designation provide an open, transparent, creator-led framework for co-creation between human directors and machine intelligence. 

Rather than viewing artificial intelligence as an autonomous substitute for human ingenuity, the AbAI-ed framework defines AI strictly as an acceleration engine, creative sparring partner, and compilation layer operated under human executive direction.

## 2. Core Criteria
To designate any code, text, music, visual asset, or system build as **AbAI-ed**, it must fulfill three requirements:

1. **Human Architecture:** Problem decomposition, creative direction, thematic constraints, and core logic originate strictly from human intent.
2. **Algorithmic Co-Production:** Machine intelligence models are actively utilized for iteration, syntax compilation, sound design, phonetic cadence, or rapid execution.
3. **Executive Verification & Taste:** The resulting output is curated, tested, debugged, and ratified by the human director before release. Unvetted generation dumps do not qualify.

## 3. Designated Tags & Syntax
Creators may denote compliant work using:
- `AbAI`: The standard specification reference.
- `AbAI-ed`: Process verification tag (e.g., in commit messages, descriptions, or project manifests).
- `[AbAI-ed]`: Monospace inline badge for changelogs, metadata, and track titles.
